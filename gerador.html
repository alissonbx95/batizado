Gerador de links personalizados

Use esta página só para você criar os links de cada convidado. O convite público fica no index.html e não mostra esta área.

Abrir
Quando você publicar no GitHub Pages, esta página vai gerar links como: ?nome=Maria, ?nome=João etc., sempre usando a mesma página principal.

Exemplos

Para uma pessoa .../index.html?nome=Maria
Para um casal ou família .../index.html?nome=Família%20Silva
